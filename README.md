# 灵巧手控制系统

面向五指腱绳驱动灵巧手的控制项目，包含嵌入式固件、Python控制接口、ROS2节点和手部动作重定向模块，支持关节目标控制、抓握动作序列和摄像头遥操作。

系统采用Seeed Studio XIAO ESP32-S3主控与七个HLS3606M智能总线舵机，驱动十六个机械关节。拇指使用三个执行器，其余四指分别由一个执行器带动联动关节；上位机通过USB串口发送控制指令并读取执行器状态。

## 主要功能

- **底层控制**：舵机位置与力矩指令、回零标定、ID配置、行程微调及温度保护。
- **Python控制**：关节到执行器的映射、动作序列、状态读取与图形化调试。
- **ROS2通信**：左右手控制节点、关节与执行器消息，以及URDF和RViz可视化。
- **视觉遥操作**：通过摄像头提取手部关键点，完成动作重定向并生成灵巧手控制目标。

代码按`firmware`、`sdk`、`ros2`和`hardware`分层组织。技术栈包括Arduino、FreeRTOS、Python、ROS2、OpenCV与MediaPipe。十六个机械关节通过七个执行器耦合驱动，执行器反馈不等同于十六个关节的独立测量。
